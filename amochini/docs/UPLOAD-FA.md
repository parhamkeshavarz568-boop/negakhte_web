# راهنمای آپلود سایت عمو چینی روی هاست

> این فایل خلاصه‌ی فارسیِ `docs/LAUNCH.md` است. اگر جایی گیر کردید، نسخه‌ی کامل انگلیسی را ببینید.

---

## ۱) کدام پوشه را آپلود کنیم؟

فقط و فقط **محتویات داخل پوشه‌ی `amochini/public/`**.

بقیه‌ی مخزن — یعنی `build/`, `docs/`, `original/` — **نباید** روی هاست برود. آن‌ها ابزار
ساخت سایت هستند، نه خودِ سایت.

نکته‌ی مهم: محتویات `public/` باید **مستقیم داخل `public_html/`** بریزد، نه داخل یک
پوشه‌ی دیگر. یعنی نتیجه باید این شکلی باشد:

```
public_html/
├── index.html
├── .htaccess
├── robots.txt
├── sitemap.xml
├── assets/
├── brake-discs/
├── brake-pads/
├── brands/
└── ...
```

اگر اشتباهی به این شکل بشود، سایت باز نمی‌شود:

```
public_html/
└── public/          ❌ غلط
    └── index.html
```

## ۲) روش اول — با File Manager در cPanel (ساده‌تر)

۱. روی کامپیوتر خودتان، **داخل** پوشه‌ی `amochini/public` بروید، همه‌چیز را انتخاب
   کنید (`Ctrl+A`) و یک فایل `site.zip` بسازید.
   ⚠️ روی خودِ پوشه‌ی `public` راست‌کلیک نکنید — آن‌وقت زیپ یک پوشه‌ی اضافه می‌سازد.

۲. وارد cPanel شوید → **File Manager** → پوشه‌ی `public_html`.

۳. از منوی بالا **Settings** را بزنید و تیک **Show Hidden Files (dotfiles)** را
   روشن کنید. بدون این کار فایل `.htaccess` را اصلاً نمی‌بینید.

۴. اگر چیزی از سایت قدیمی داخل `public_html` هست، اول از آن یک پشتیبان بگیرید
   (همه را زیپ کنید و زیپ را دانلود کنید)، بعد پاکش کنید.

۵. دکمه‌ی **Upload** → فایل `site.zip` را بفرستید.

۶. برگردید به `public_html` → روی `site.zip` راست‌کلیک → **Extract**.

۷. بعد از باز شدن، خودِ `site.zip` را پاک کنید.

۸. چک کنید که `index.html` و `.htaccess` مستقیم داخل `public_html` باشند.

---

## ۳) روش دوم — با FTP (مثلاً FileZilla)

۱. با اطلاعات FTP هاست وصل شوید.

۲. در FileZilla از منوی **Server** گزینه‌ی **Force showing hidden files** را روشن
   کنید، وگرنه `.htaccess` آپلود نمی‌شود.

۳. سمت راست بروید داخل `public_html`.

۴. سمت چپ بروید **داخل** `amochini/public`، همه‌ی فایل‌ها و پوشه‌ها را انتخاب کنید و
   بکشید سمت راست.

۵. حدود ۲۹۱ فایل و ۱۲ مگابایت است؛ با FTP کمی طول می‌کشد. اگر عجله دارید، روش
   زیپ (روش اول) خیلی سریع‌تر است.

## ۴) بعد از آپلود — این چند مورد را چک کنید

| چه چیزی | چطور | جواب درست |
|---|---|---|
| صفحه‌ی اصلی | `amochini.ir` را باز کنید | سایت با لوگو و تابلوی قیمت بالا می‌آید |
| یک صفحه‌ی داخلی | `amochini.ir/prices/` | تابلوی قیمت‌ها |
| صفحه‌ی ۴۰۴ | `amochini.ir/chizi-ke-nist` | صفحه‌ی ۴۰۴ فارسی، نه ارور خام هاست |
| نقشه‌ی سایت | `amochini.ir/sitemap.xml` | یک فایل XML |
| فونت‌ها و عکس‌ها | صفحه را `Ctrl+Shift+R` کنید | فونت فارسی درست، لوگو سرجایش |

اگر صفحه‌ی ۴۰۴ کار نکرد یعنی `.htaccess` یا آپلود نشده، یا سرور **nginx** است
(nginx فایل `.htaccess` را کلاً نادیده می‌گیرد). در این حالت از پشتیبان هاست
بپرسید سرور Apache/LiteSpeed است یا nginx، و به من بگویید تا کانفیگ nginx را
بنویسم.

## ۵) دو کار باقی‌مانده قبل از تبلیغ سایت

۱. **کد نماد اعتماد الکترونیکی (eNamad) و کد ساماندهی** هنوز خالی است. بعد از
   گرفتن کدها، آن‌ها را در فایل `build/site_config.py` بگذارید و سایت را دوباره
   بسازید.

۲. **گواهی SSL (https)**. الان سایت روی `http://` منتشر می‌شود. هر وقت روی هاست
   SSL فعال شد و این دستور از بیرون ایران جواب درست داد:

   ```
   curl -I https://amochini.ir/
   ```

   در فایل `build/site_config.py` مقدار `SCHEME` را به `"https"` تغییر دهید و
   دوباره بسازید.

---

## ۶) برای به‌روزرسانی‌های بعدی

هر بار که سایت دوباره ساخته می‌شود، فقط کافی است محتویات جدید `public/` را
دوباره روی `public_html` بریزید (Overwrite). لازم نیست چیزی پاک کنید، مگر اینکه
صفحه‌ای حذف شده باشد.
